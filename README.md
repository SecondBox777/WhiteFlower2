# Mindscope

한국어 인지 능력 테스트 웹사이트 프로토타입. 반응형 소개 페이지 → 30문항·30분 테스트 → 시간 보정 채점 → 예비 IQ 결과 화면을 제공합니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

http://localhost:3000 에서 확인하세요. `PORT` 환경변수로 포트를 변경할 수 있습니다.

```sh
npm test
```

## 구성

- `index.html`: 소개, 인지 영역, 리포트 예시, FAQ
- `style.css`: 데스크톱·모바일 스타일, 기하학 일러스트
- `questions.js`: Q01~Q30 이미지 문항 (총 30문항)
- `app.js`: 문항 이동, 응답 수정, 30분 시간 바, 자동 제출, 즉시 결과
- `server.mjs`: 허용된 정적 파일만 제공하는 로컬 서버

## 문항 교체

`Q01.webp`~`Q30.webp`를 순서대로 표시하며 A~D 선택지를 제공합니다. 모든 30문항에 실제 문제가 연결되어 있습니다. 문항 목록을 기준으로 로컬 서버와 배포 빌드에도 모든 이미지를 포함합니다.

`IQ테스트 답지.xlsx`의 정답·배점과 `simulation/results.json`의 기준시간을 `scoring.js`에 반영했습니다. 점수는 정답 문항의 `P × (0.8 + 0.2S)` 합계이며, IQ는 `79.76334234199149 + 0.6930466663250522 × Score`로 추정합니다. IQ 110 집단의 평균 약 41점은 평균 점수 곡선의 기준이며 회귀식의 고정 통과점이 아닙니다.

문항별 누적 풀이 시간이 기준시간의 5% 미만(문항에 따라 1~4.5초)이면 정답이어도 그 문항은 0점 처리합니다. 이는 원본 합성 시뮬레이션에 없던 제품 규칙이며, 원본 규준을 재보정한 것은 아닙니다. 문제 화면에는 영역명, 공통 안내 제목, A~D 보기와 이전·다음 버튼을 표시합니다. 닫기 버튼은 타이머 위의 별도 공간에 배치합니다.

TEST 시작 시 30분을 측정합니다. 문항별 시간은 화면에 표시하지 않고 방문 시간을 누적합니다. 이전 문항 재방문, 창 닫기와 탭 이동 중에도 시간은 흐릅니다. 30분 종료 시 해당 문항과 미응답은 0점으로 자동 제출합니다. 새로고침하면 초기화됩니다. 시간제한은 합성 자료의 별도 민감도 조건이므로 기본 회귀 환산과 같은 검증된 규준으로 해석할 수 없습니다.

`simulation/`에는 제공된 보고서·결과 JSON·원본 시뮬레이션 스크립트를 보존했습니다. 재현할 때는 별도 실행 사본의 경로와 한국어 글꼴을 Codespace에 맞게 조정하고 numpy·matplotlib를 설치한 뒤 별도 출력 폴더를 사용하세요. 이번 변경에서는 시뮬레이션을 재실행하지 않았습니다.

문항 이미지는 원본 1254×1254 해상도를 유지한 WebP로 제공합니다. Q01~Q10은 품질 85, Q11~Q30은 품질 80 및 effort 6으로 압축했습니다. 원본 PNG는 편집용으로 보관하고 배포에는 포함하지 않습니다. 원본을 교체하면 같은 이름의 WebP도 다시 압축해 갱신하세요.

첫 문제는 페이지 진입 시, 첫 3문제는 시작 안내 화면에서 미리 불러옵니다. 이후 다음 4문제를 미리 다운로드·디코딩해 문항 전환 시 대기를 줄입니다. 네트워크 요청이나 디코딩 완료를 기다리느라 다음 버튼을 막지 않습니다. 느린 네트워크에서 대기가 전혀 발생하지 않는 것을 보장하지는 않습니다.

## Cloudflare 배포

배포용 파일은 `npm run build`로 생성하는 `dist/`에만 담깁니다. HTML, CSS, 브라우저 JavaScript 및 문항 파일과 Q01~Q30 WebP 이미지 총 35개를 복사합니다. `node_modules`, 로컬 서버, 테스트, 환경변수 파일은 포함하지 않습니다. 문항을 줄이거나 제거할 필요가 없습니다.

### Workers Git 연동

기존 Workers 프로젝트와 GitHub 연결을 유지합니다. `wrangler.jsonc`의 `main`은 `src/index.js`이며 `dist`를 `ASSETS` binding으로 제공합니다. `/api/*`는 Worker가 먼저 처리합니다. 배포 명령은 `npx wrangler deploy`이며 Wrangler의 `build.command`가 `npm run build`를 실행합니다. Dashboard 빌드 명령은 비워도 되고 기존 `npm run build`를 유지해도 됩니다(후자는 빌드가 두 번 실행됩니다).

CLI 배포는 `npm run deploy`, 로컬 Worker 실행은 `npm run worker:dev`입니다. 기존 `npm run dev`는 정적 화면만 확인합니다. 실제 Dashboard 프로젝트 이름이 다르면 `wrangler.jsonc`의 `name`을 해당 이름과 맞추세요.

### 25 MiB 오류의 원인

`node_modules/workerd/bin/workerd`는 배포 도구의 실행 파일이며 웹사이트 콘텐츠가 아닙니다. 저장소 전체를 정적 에셋으로 지정하면 이 파일까지 업로드되어 크기 제한을 초과할 수 있습니다. `.gitignore`만 추가하는 대신, 공개 파일만 담은 `dist`로 업로드 범위를 제한해 해결합니다.

## 테스트 버전의 범위

현재는 결제 없이 테스트 완료 후 성인 확인을 거쳐 AI 보고서를 요청합니다. 생성 중에는 로딩 안내를, 완료 시에는 전체 보고서를 같은 화면에 표시합니다. 이메일 입력은 별도 발송을 요청할 때만 필요합니다. 응답은 브라우저 메모리에서 유지되며, 전송 안내에 따라 사용자가 AI 보고서를 요청하면 응답·시간·채점 통계를 OpenAI에 전송합니다. 답지는 체험용 클라이언트 모듈에 포함되어 있습니다. 실제 유료 서비스로 전환할 때는 세션 저장·결제 확인을 구현해야 합니다. 서버 채점과 Resend 이메일 발송은 구현되어 있습니다.

결과는 확률 모형으로 생성한 합성·예비 자료에 기반하며 검증된 IQ 규준이 아닙니다. 실제 사람이나 AI가 문항을 풀어 얻은 결과가 아니며, 현재 실행 중인 AI 모델이 응시자를 평가하는 방식도 아닙니다. 선형 회귀의 극단 점수 결과는 특히 해석이 제한됩니다. 소개 화면의 영역별 차트는 실제 결과와 무관한 예시입니다.

## OpenAI AI 보고서 (Cloudflare Worker)

브라우저 → `POST /api/analyze` → Worker → OpenAI Responses API로 연결됩니다. 결과 전송 안내에 따라 보고서 요청 시 한국어/영어 보고서를 생성하며 서버에서 다시 채점합니다. 강점을 소개하는 첫 문단·문제풀이 3개·인지적 특성·추천 직업 2개와 요구 능력을 제공합니다. 프롬프트는 `lib/report-prompt.js`, 출력 형식은 `lib/report.js`에서 수정합니다.

먼저 Worker 코드를 배포한 뒤 Workers & Pages → 기존 Worker → Settings → Variables and Secrets에 `OPENAI_API_KEY`를 Secret으로, `OPENAI_MODEL`을 텍스트 변수로 추가하고 배포합니다. 빌드 환경변수가 아닌 Worker 런타임 설정입니다. `keep_vars: true`로 Dashboard에서 설정한 텍스트 변수를 다음 Wrangler 배포에서도 유지합니다. 키는 소스나 공개 파일에 포함하지 않습니다.

[설정과 데이터 전달 형식](docs/openai-report.md)을 참고하세요.

테스트 시작 안내의 **랜덤 답안 제출 · 실험용** 버튼은 A~D 중 무작위 30개 답안과 문항 기준시간의 60~140% 범위 가상 시간을 생성하여 즉시 결과로 이동합니다. 총 시간은 30분 미만으로 제한합니다. AI 보고서는 생성 버튼으로 요청하며 서버와 모델에도 실험 데이터임을 전달합니다.

보고서는 30문항의 검토된 과제 태그와 상대 풀이시간·난이도·정답 여부를 교차 분석합니다. [문항별 분류와 지표 정의](docs/item-analysis.md)를 참고하세요. 프롬프트는 `lib/report-prompt.js`, 내부 문항 분류는 `lib/item-metadata.js`, 지표 계산은 `lib/performance.js`에서 수정합니다.

## 일시 중지 해제

결과 화면에서 생성된 AI 보고서를 이메일로 받을 수 있는 Resend 연동을 구현했습니다. [Resend 계정·도메인·Worker 설정 안내](docs/resend-email.md)를 따라 `RESEND_API_KEY`, `RESEND_FROM`, `REPORT_EMAIL_SECRET`을 등록하세요. 보고서 중지 설정은 이메일 API에도 적용됩니다. 이메일 전송은 이미 생성된 보고서를 사용하므로 OpenAI를 다시 호출하지 않습니다.

현재 테스트·결과 리포트 생성·이메일 발송·사진 저장·공유를 일시 중지했습니다. `app.js`의 `TESTING_PAUSED`와 `REPORTS_PAUSED`는 모두 `true`이며, `wrangler.jsonc`의 대응 변수도 모두 문자열 `"true"`입니다. 재개하려면 두 파일의 대응 값을 모두 `false`와 문자열 `"false"`로 변경하고 배포합니다. 보고서와 이메일 발송을 중지하려면 `app.js`의 `REPORTS_PAUSED`를 `true`로, `wrangler.jsonc`의 `vars.REPORTS_PAUSED`를 문자열 `"true"`로 변경하고 GitHub에 push합니다. 전체 테스트를 중지하려면 두 파일의 `TESTING_PAUSED`를 각각 `true`와 문자열 `"true"`로 설정합니다. 서버는 중지 상태에서 요청 본문을 읽거나 OpenAI를 호출하기 전에 503으로 응답하므로, 오래 열린 페이지나 직접 API 요청도 보고서를 생성하지 못합니다. API 키는 그대로 보관합니다.

보고서 요청 직전에 기본 해제된 만 18세 이상 확인란을 제공합니다. 확인 전에는 보고서 버튼이 비활성화되고, 리포트 생성·이메일 API도 `adultConfirmed: true`가 없는 요청을 거절합니다. 테스트 소개와 시작 화면에는 연령 확인을 추가하지 않았습니다. 하단 이용약관에는 성인 대상, 18세 미만 이용·구매 제한 및 오락·자기 탐색 목적을 명시했습니다.

## 화면 보고서·사진 저장·공유

결과 화면에서 언어 선택 → 성인 확인 → 결과 리포트 받아보기 순서로 생성합니다. 이메일 주소 없이 화면에서 읽을 수 있으며 생성 실패 시 같은 버튼으로 재시도할 수 있습니다. 화면과 이메일은 `report-content.js`의 동일한 렌더러를 사용합니다. 이메일 버튼은 이미 생성된 보고서만 발송하며 OpenAI를 다시 호출하지 않습니다. 이메일 설정이 없어도 화면·사진 저장·공유 기능은 사용할 수 있습니다.

보고서 하단의 사진으로 저장은 `report-export.js`에서 전체 내용을 PNG로 그려 다운로드합니다. 긴 보고서는 여러 장으로 나누고 각 저장 링크를 제공합니다. 지원하는 브라우저에서는 공유 버튼으로 시스템 공유창을 열고, 준비된 PNG 또는 보고서 텍스트를 전달합니다. 그 외에는 텍스트 복사 또는 선택 가능한 텍스트로 공유할 수 있습니다. 보고서를 공개 URL로 업로드하지 않습니다. 새 테스트를 시작하거나 새로고침하면 보고서는 초기화됩니다.
