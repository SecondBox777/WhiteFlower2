# Mindscope

한국어 인지 능력 테스트 웹사이트 프로토타입. 반응형 소개 페이지 → 30문항·30분 테스트 → 시간 보정 채점 → 예비 IQ 결과 화면을 제공합니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

http://localhost:3000 에서 확인하세요. `PORT` 환경변수로 포트를 변경할 수 있습니다.

```sh
npm test
```

## 구성

- `index.html`: 소개, 인지 영역, 리포트 예시, FAQ
- `style.css`: 데스크톱·모바일 스타일, 기하학 일러스트
- `questions.js`: Q01~Q30 이미지 문항 (총 30문항)
- `app.js`: 문항 이동, 응답 수정, 30분 시간 바, 자동 제출, 즉시 결과
- `server.mjs`: 허용된 정적 파일만 제공하는 로컬 서버

## 문항 교체

`Q01.webp`~`Q30.webp`를 순서대로 표시하며 A~D 선택지를 제공합니다. 모든 30문항에 실제 문제가 연결되어 있습니다. 문항 목록을 기준으로 로컬 서버와 배포 빌드에도 모든 이미지를 포함합니다.

제공받은 답지 엑셀의 정답·배점과 `simulation/results.json`의 기준시간을 `scoring.js`에 반영했습니다. 서비스에서 사용하지 않는 원본 답지 엑셀은 정리했으며 정답·배점은 `scoring.js`에 유지합니다. 점수는 정답 문항의 `P × (0.8 + 0.2S)` 합계이며, IQ는 `79.76334234199149 + 0.6930466663250522 × Score`로 추정합니다. IQ 110 집단의 평균 약 41점은 평균 점수 곡선의 기준이며 회귀식의 고정 통과점이 아닙니다.

문항별 누적 풀이 시간이 기준시간의 5% 미만(문항에 따라 1~4.5초)이면 정답이어도 그 문항은 0점 처리합니다. 이는 원본 합성 시뮬레이션에 없던 제품 규칙이며, 원본 규준을 재보정한 것은 아닙니다. 문제 화면에는 영역명, 공통 안내 제목, A~D 보기와 이전·다음 버튼을 표시합니다. 닫기 버튼은 타이머 위의 별도 공간에 배치합니다.

TEST 시작 시 30분을 측정합니다. 문항별 시간은 화면에 표시하지 않고 방문 시간을 누적합니다. 이전 문항 재방문, 창 닫기와 탭 이동 중에도 시간은 흐릅니다. 30분 종료 시 해당 문항과 미응답은 0점으로 자동 제출합니다. 새로고침하면 초기화됩니다. 시간제한은 합성 자료의 별도 민감도 조건이므로 기본 회귀 환산과 같은 검증된 규준으로 해석할 수 없습니다.

`simulation/`에는 제공된 보고서·결과 JSON·원본 시뮬레이션 스크립트를 보존했습니다. 재현할 때는 별도 실행 사본의 경로와 한국어 글꼴을 Codespace에 맞게 조정하고 numpy·matplotlib를 설치한 뒤 별도 출력 폴더를 사용하세요. 이번 변경에서는 시뮬레이션을 재실행하지 않았습니다.

문항 이미지는 원본 1254×1254 해상도를 유지한 WebP로 제공합니다. Q01~Q10은 품질 85, Q11~Q30은 품질 80 및 effort 6으로 압축했습니다. 서비스에서 사용하지 않는 원본 PNG는 정리했습니다. 문항을 교체할 때는 같은 이름의 WebP를 갱신하세요.

첫 문제는 페이지 진입 시, 첫 3문제는 시작 안내 화면에서 미리 불러옵니다. 이후 다음 4문제를 미리 다운로드·디코딩해 문항 전환 시 대기를 줄입니다. 네트워크 요청이나 디코딩 완료를 기다리느라 다음 버튼을 막지 않습니다. 느린 네트워크에서 대기가 전혀 발생하지 않는 것을 보장하지는 않습니다.

## Cloudflare 배포

배포용 파일은 `npm run build`로 생성하는 `dist/`에만 담깁니다. HTML, CSS, 브라우저 JavaScript, 번역 카탈로그와 Q01~Q30 WebP 이미지를 복사합니다. `node_modules`, 로컬 서버, 테스트, 환경변수 파일은 포함하지 않습니다. 문항을 줄이거나 제거할 필요가 없습니다.

### Workers Git 연동

기존 Workers 프로젝트와 GitHub 연결을 유지합니다. `wrangler.jsonc`의 `main`은 `src/index.js`이며 `dist`를 `ASSETS` binding으로 제공합니다. `/api/*`는 Worker가 먼저 처리합니다. 배포 명령은 `npx wrangler deploy`이며 Wrangler의 `build.command`가 `npm run build`를 실행합니다. Dashboard 빌드 명령은 비워도 되고 기존 `npm run build`를 유지해도 됩니다(후자는 빌드가 두 번 실행됩니다).

CLI 배포는 `npm run deploy`, 로컬 Worker 실행은 `npm run worker:dev`입니다. 기존 `npm run dev`는 정적 화면만 확인합니다. 실제 Dashboard 프로젝트 이름이 다르면 `wrangler.jsonc`의 `name`을 해당 이름과 맞추세요.

### 25 MiB 오류의 원인

`node_modules/workerd/bin/workerd`는 배포 도구의 실행 파일이며 웹사이트 콘텐츠가 아닙니다. 저장소 전체를 정적 에셋으로 지정하면 이 파일까지 업로드되어 크기 제한을 초과할 수 있습니다. `.gitignore`만 추가하는 대신, 공개 파일만 담은 `dist`로 업로드 범위를 제한해 해결합니다.

## 테스트 버전의 범위

테스트는 무료이며, 완료 후 성인 확인을 거쳐 Polar에서 1회 결제하면 퍼즐 보고서를 요청할 수 있습니다. 생성 중에는 로딩 안내를, 완료 시에는 전체 보고서를 같은 화면에 표시합니다. 결제 전에 리포트 수신 이메일을 입력하며, 보고서 생성 직후 서버에서 자동 발송합니다. 테스트 중 응답은 브라우저 메모리에서 유지되며, 결제 페이지로 이동할 때 서버의 Durable Object에 30일간 저장합니다. 보고서는 서버에서 직접 생성하며 외부 AI로 정보를 전송하지 않습니다. 답지는 체험용 클라이언트 모듈에 포함되어 있습니다. 결제 상태는 Polar API로 서버에서 확인하며, 구매별로 생성된 보고서를 저장해 재요청 시 재사용합니다. 서버 채점과 Resend 이메일 발송은 구현되어 있습니다.

결과는 확률 모형으로 생성한 합성·예비 자료에 기반하며 검증된 IQ 규준이 아닙니다. 실제 사람이나 AI가 문항을 풀어 얻은 결과가 아니며, 현재 실행 중인 AI 모델이 응시자를 평가하는 방식도 아닙니다. 선형 회귀의 극단 점수 결과는 특히 해석이 제한됩니다. 소개 화면의 영역별 차트는 실제 결과와 무관한 예시입니다.

## 내부 생성 퍼즐 보고서

답안과 시간을 서버에서 다시 채점하고 기존 선형 회귀식으로 재미용 IQ 스타일 점수를 계산합니다. 외부 AI 호출과 API 키는 필요하지 않습니다. 공인 IQ 검사가 아니며 과학적으로 검증된 실제 IQ가 아닙니다.

패턴인식능력·논리추론능력·공간지각능력을 0~5칸으로 표시합니다. 영역별 획득점수/최대점수를 5칸으로 반올림합니다. 정답 점수 80%, 정답 풀이 속도 최대 20%이며 내부 기준시간을 사용합니다. 인구 규준이나 다른 사람과의 순위가 아닙니다. 보고서에는 전체 총점과 영역별 점수·시간만 표시하며 정답 개수와 문항별 내역은 제공하지 않습니다. 막대 0~2칸은 보완 필요, 3칸은 평범, 4칸은 우수, 5칸은 매우 우수로 내부 기준에 따라 평가합니다. 강점·약점·직업 추천은 제공하지 않습니다.

Polar 1회 결제 확인 후 보고서를 생성하고 Resend로 자동 이메일 발송합니다. 화면·이메일·사진 내보내기는 동일한 내용을 사용합니다. 이메일 설정은 [Resend 안내](docs/resend-email.md)를 참고하세요. 답안과 구매 보고서는 Cloudflare에 30일 보관합니다.

현재 테스트·결제·보고서·이메일 기능은 활성화되어 있습니다. `app.js`와 `wrangler.jsonc`의 두 PAUSED 설정은 모두 false입니다. Polar 환경은 production이며 운영 상품 `d8ec786b-c015-47dd-94c3-19c769ae9069`를 사용합니다. 리포트는 결제 확인 후 생성하며 임시 무료 리포트와 랜덤 답안 제출 기능은 제거했습니다. 운영 토큰은 Cloudflare의 `POLAR_ACCESS_TOKEN` Secret에 등록합니다.

## 다국어 지원

한국어(`ko`), 영어(`en`), 일본어(`ja`), 중국어 간체(`zh-CN`), 스페인어(`es`), 프랑스어(`fr`)를 지원합니다. 상단 Language 메뉴에서 변경하며 `?lang=es`처럼 링크로 지정할 수도 있습니다. URL 지정 → 저장된 선택 → 브라우저 언어 순서로 적용하며, 미지원 언어는 영어를 사용합니다.

홈페이지·약관·문제 안내·상태 메시지는 `translations.js`와 `i18n.js`, 문항별 안내는 `question-locales.js`에서 관리합니다. 원본 문제 그림에 포함된 영어 지시문의 의미를 별도 번역 안내로 제공하며, 저울의 무게 조건과 D 선택지의 “판단할 수 없음”도 번역합니다. 도형·문항 순서·정답 위치·채점은 모든 언어에서 동일합니다.

페이지 언어가 보고서의 기본 언어입니다. 결제 전 결과 화면에서 보고서 언어를 별도로 고를 수 있습니다. 선택한 언어를 구매 데이터에 저장하며 결제 복귀 시 해당 언어를 복원합니다. 구매 후 생성·재시도·캐시·자동 이메일은 저장된 언어를 사용합니다. `report-locales.js`의 문구와 `report-content.js`의 공통 렌더러가 화면·이메일 제목/본문·공유·PNG 보고서에 적용됩니다. API 오류는 `X-Mindscope-Language` 헤더를 사용합니다.

현재 보고서는 외부 AI 프롬프트를 사용하지 않고 서버 내부 채점식으로 생성합니다. 새로운 언어를 추가할 때는 언어 목록과 세 번역 카탈로그를 함께 확장하고 `npm test`로 누락·구매 복원·메일·보고서 검증을 실행하세요. 서비스 일시 중지 플래그는 다국어 지원과 별도로 유지합니다.

보고서는 크림색 종이·잉크색 표지와 세 가지 색상의 수행 지표를 사용하는 두 장 구성입니다. 첫 장은 점수·프로필·요약, 두 번째 장은 영역별 카드·산출 방식·해석 안내를 담습니다. 화면과 HTML 이메일은 공통 렌더러를, PNG는 같은 색상·문구·수치의 캔버스 레이아웃을 사용합니다. 기본 보고서는 PNG 두 장으로 저장하며, 비정상적으로 긴 문구도 후속 페이지로 이어 저장합니다. `node scripts/export-report-example.mjs`로 샘플 HTML을 갱신할 수 있습니다.

SNS 공유는 결과 사진을 블러 없이 사용하는 서비스 선택 메뉴로 제공합니다. PC는 결과별 이미지 미리보기 링크와 사진/문구 복사·저장을, 지원 기기는 PNG 파일과 문구를 함께 보내는 기기 공유를 사용합니다. 카카오 직접 공유용 `KAKAO_JAVASCRIPT_KEY` 설정과 7일 공유 링크 저장·삭제 방식은 [SNS 공유 안내](docs/social-sharing.md)를 참고하세요.
