# Mindscope

한국어 인지 능력 테스트 웹사이트 프로토타입. 반응형 소개 페이지 → 20문항 테스트 → 이메일 입력 → 결제 흐름 체험 → 완료 화면을 제공합니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

http://localhost:3000 에서 확인하세요. `PORT` 환경변수로 포트를 변경할 수 있습니다.

```sh
npm test
```

## 구성

- `index.html`: 소개, 인지 영역, 리포트 예시, FAQ
- `style.css`: 데스크톱·모바일 스타일, 기하학 일러스트
- `questions.js`: 네 영역별 5개씩 총 20개 예시 문항과 정답·해설
- `app.js`: 문항 이동, 응답 수정, 이메일 검증, 데모 결제 흐름
- `server.mjs`: 허용된 정적 파일만 제공하는 로컬 서버

## 데모 범위

실제 결제, IQ 산출, 결과 분석지 생성 및 이메일 발송은 구현되지 않았습니다. 응답은 브라우저 메모리에만 유지되며 새로고침하면 사라집니다. 이메일은 외부로 전송하거나 영구 저장하지 않습니다. 완료 창을 닫으면 입력 이메일이 화면에서 제거됩니다. Google Fonts를 불러오며 연결할 수 없으면 시스템 글꼴을 사용합니다.

문항은 표준화·규준화되지 않은 예시이므로 실제 IQ나 백분위를 산출하지 않습니다. 소개 화면의 리포트 차트는 예시 데이터입니다. 4,900원은 변경 가능한 예시 가격입니다.

## 실제 서비스 연결 시 필요한 구현

1. 서버에 테스트 세션과 응답을 저장하고 서버에서 채점합니다. 정답은 클라이언트 번들에서 제거하고 보호된 저장소로 이동합니다.
2. 서버에서 주문을 생성하고 결제 제공업체의 결제창으로 연결합니다. 금액·상품·주문 소유자를 서버에서 검증합니다.
3. 서명을 검증한 결제 웹훅에서 실제 결제 상태와 금액을 확인합니다. 브라우저의 성공 화면만으로 결제를 승인하지 않습니다.
4. 결제 완료 주문만 리포트 생성·메일 작업에 등록합니다. 주문 ID 기준 중복 처리를 막고 발송 실패 재시도와 상태 조회를 구현합니다.
5. 이메일 제공업체와 PDF/HTML 리포트 템플릿을 연결합니다. API 키는 서버 환경변수로 관리합니다. 리포트 접근 시 결제 여부와 사용자 권한을 확인합니다.
6. 개인정보 수집·보관·삭제 기준, 구매 및 환불 안내를 실제 운영 내용에 맞게 준비합니다. 정식 IQ 점수를 제공하려면 전문가의 검사 설계·표준화가 필요합니다.

현재 정적 데모는 결제 권한을 보호하는 실제 백엔드가 아니므로 유료 서비스로 바로 배포하면 안 됩니다.
